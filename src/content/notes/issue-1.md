# 从最小二乘推导简单线性回归

## 一、直观引入

给定平面上的一批观测点 $(x_i,y_i)$，我们想用一条直线 $\hat{y}=ax+b$ 来“代表”它们。数据点一般不会恰好落在同一条直线上，因此需要先定义什么叫“拟合得好”，再求出使它最优的 $a$ 与 $b$。最小二乘法的选择是：**最小化残差的平方和**。本文按“定义模型与损失 → 求导得到正规方程 → 数值算例 → 概念辨析（共线、相关与因果、离群点）”的顺序展开。

## 二、模型、符号与损失函数

一元线性模型写作

$$y_i = a x_i + b + \varepsilon_i, \qquad i=1,\times,n,$$

其中 $a$ 是斜率，$b$ 是截距，$\varepsilon_i$ 表示模型未能捕捉的误差成分（这是一个**假设**，而非可直接观测的量）。给定参数后，预测值与残差分别为

$$\hat{y}_i = a x_i + b, \qquad e_i = y_i - \hat{y}_i .$$

最小二乘的目标函数（平方损失）为

$$S(a,b) = \sum_{i=1}^{n} e_i^{2} = \sum_{i=1}^{n}\bigl(y_i - a x_i - b\bigr)^{2}.$$

采用平方形式的直观理由：它把正负残差都变成非负数，避免相互抵消；同时平方是“惩罚越重、误差越大增长越快”的对称度量。

## 三、为什么平方损失便于求导

$S(a,b)$ 是关于 $(a,b)$ 的二元二次多项式，因此在整个平面上处处可微，且梯度

$$\frac{\partial S}{\partial a} = -2\sum_i x_i\bigl(y_i - a x_i - b\bigr), \qquad \frac{\partial S}{\partial b} = -2\sum_i \bigl(y_i - a x_i - b\bigr)$$

在任意点都存在，直接令其为零即可得到驻点。更重要的是，$S$ 的 Hessian 为 $2X^{\top}X$，它是半正定的，所以驻点就是全局最小值点，不存在“陷入局部极小”的问题。

对比之下，绝对值损失 $\sum_i \elvert e_i\vert$ 在 $e_i=0$ 处不可导，需要引入次梯度或迭代算法。另一条常被引用的理由是：若进一步假设 $\varepsilon_i$ 独立同分布于高斯分布，最小二乘与极大似然估计重合——这是**附加假设下的推论**，不是最小二乘定义本身。

## 四、正规方程的推导

令两个偏导数为零并除以 $-2$：

$$\begin{cases}
 a\sum_i x_i^{2} + b\sum_i x_i = \sum_i x_i y_i,\\
 a\sum_i x_i + n b = \sum_i y_i.
\end{cases}$$

这就是**正规方程组**。写成矩阵形式，令

$$X=\begin{pmatrix} x_1 & 1 \\vdots & \vdots \ x_n & 1\end{pmatrix},\qquad \theta=\begin{pmatrix}a\\b\end{pmatrix},\qquad y=\begin{pmatrix}y_1\\vdots\y_n\end{pmatrix},$$

则方程组等价于

$$X^{\top}X\theta = X^{\top}y .$$

由第二式得 $b=\bar{y}-a\bar{x}$，代入第一式可解出

$$a = \frac{\sum_i (x_i-\bar{x})(y_i-\bar{y})}{\sum_i (x_i-\bar{x})^{2}} = \frac{S_{xy}}{S_{xx}} .$$

注意：第二式同时意味着 $a\bar{x}+b=\bar{y}$，即**残差之和恒为零**——这是方程的代数结果，并不代表拟合“无偏”或数据被完美解释。

## 五、逐步算例：$(0,1)$、$(1,2)$、$(2,2)$

先算所需和：$n=3$，$\sum x_i=3$，$\sum y_i=5$，$\sum x_i^{2}=5$，$\sum x_i y_i = 0\times1+1\times2+2\times2=6$。

代入正规方程：

$$\begin{cases} 5a+3b=6,\\ 3a+3b=5.\end{cases}$$

两式相减得 $2a=1$，故 $a=\frac12$；回代得 $3b = 5-\frac32=\frac72$，故 $b=\frac76$。

用均值法核对：$\bar{x}=1$，$\bar{y}=\frac53$，$S_{xy}=(-1)(-\frac23)+0+1\times\frac13=1$，$S_{xx}=1+0+1=2$，于是 $a=\frac{S_{xy}}{S_{xx}}=\frac12$，$b=\frac53-\frac12=\frac76$，结果一致。

预测值与残差：

| $x_i$ | $y_i$ | $\hat{y}_i$ | $e_i=y_i-\hat{y}_i$ |
|---|---|---|---|
| 0 | 1 | $7/6Zpprox1.167$ | $-1/6$ |
| 1 | 2 | $5/3Zpprox1.667$ | $1/3$ |
| 2 | 2 | $13/6Zpprox2.167$ | $-1/6$ |

核对：$\sum e_i = -\frac16+\frac13-\frac16=0$，满足正规方程第二式；平方残差和 $S=\frac1{36}+\frac19+\frac1{36}=\frac16\approx0.167$，显然非零——三个点不共线，直线无法完全拟合。

```python
import numpy as np
x = np.array([0., 1., 2.])
y = np.array([1., 2., 2.])
a, b = np.polyfit(x, y, 1)      # 等价于解正规方程
print(a, b)                      # 0.5, 1.166666...
print(np.sum((y - (a*x + b))**2))  # 0.166666...
```

## 六、为什么所有 $x_i$ 相同时斜率不能唯一确定

若所有 $x_i=x_0$，则 $S_{xx}=\sum_i(x_i-\bar{x})^{2}=0$，且 $\det(X^{\top}X)=nS_{xx}=0$，矩阵奇异，正规方程无唯一解。直接看目标函数：

$$S(a,b)=\sum_i\bigl(y_i-a x_0-b\bigr)^{2},\qquad \bar{y}=a x_0+b .$$

取 $b=\bar{y}-a x_0$ 后，$S=\sum_i(y_i-\bar{y})^{2}$ 与 $a$ 完全无关：**任意斜率都能配出同一条经过点 $(x_0,\bar{y})$ 的直线，损失都相同**。因此斜率不可识别（例如 $n$ 个点的横坐标都是 5，纵坐标各不相同，数据里根本没有“随 $x$ 变化”的信息）。

**需要澄清的一点**：横坐标全都相同，与“所有点共线”是两回事。

- **一般情况下观测点不全共线**，此时拟合残差通常为正，如第五节算例。
- 但**不能说任何数据都无法被直线完全拟合**：当所有点共线（例如 $(1,1),(2,2),(3,3)$）且横坐标不全相同时，取该直线的参数即得 $e_i\equiv0$，$S=0$。
- 当所有 $x_i$ 相同且 $y_i$ 不全相同时，既不能得到唯一斜率，也无法用一条竖直“函数式”直线完全拟合。

## 七、相关性不等于因果性

斜率 $a=\frac{S_{xy}}{S_{xx}}$ 只度量 $x$ 与 $y$ 的**线性同向/反向变动程度**，与相关系数 $r=\frac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}$ 只差一个正的尺度因子。回归给出的是“$x$ 每增加 1 单位，$y$ 的条件均值平均变化 $a$ 单位”的**统计关联描述**，而不是“改变 $x$ 会使 $y$ 改变 $a$ 单位”的干预结论。

把回归系数解释为因果效应，至少要额外假设：不存在同时影响 $x$ 与 $y$ 的混淆变量、不存在反向因果、样本选择与测量方式不会系统性偏倚等。一个常见的直觉例子是：夏季冰淇淋销量与溺水事故数同向变化，但更合理的共同原因是气温，而非冰淇淋导致溺水。这些额外假设**不能由最小二乘本身保证**。

## 八、离群点对平方损失的影响

平方损失对误差是二次增长：残差变为 2 倍，惩罚变为 4 倍。因此离群点的两类影响需要区分：

1. **纵向离群（$y_i$ 极端而 $x_i$ 常规）**：残差很大，$S$ 中该项占主导，会把拟合直线“拉”向自己，显著改变 $a$ 与 $b$。
2. **高杠杆点（$x_i$ 远离其余点）**：即使 $y_i$ 落在趋势附近，它在 $S_{xy}$ 中带有因子 $(x_i-\bar{x})$，同样会被放大。粗略地说，一个点对拟合的影响正比于其杠杆值 $h_{ii}$ 与残差 $e_i$ 的乘积。

实践中的常见应对包括：先画散点图与残差图、报告稳健回归（如 Huber 损失、最小绝对偏差）作为对照、或事先依据领域知识剔除明显的录入错误。这些做法各有代价：Huber 损失在零点附近才可导，最小绝对偏差没有闭式解，剔除数据则必须有正当理由，否则是在“挑选结论”。

## 九、常见误区与局限

- 把 $r$ 大或 $S$ 小直接读作“$x$ 导致 $y$”。
- 在样本 $x$ 范围之外**外推**：线性关系未必在数据范围外延续。
- 忽略设计矩阵的秩：$X^{\top}X$ 奇异（横坐标全同、或多变量中的完全共线）时解不唯一。
- 把“残差和为 0”误解为“模型没有系统性偏差”。
- 只看总体 $S$ 而不看残差结构：若残差随 $x$ 呈喇叭形（异方差）或弯曲（模型形式不合适），系数估计仍可计算，但其标准误与推断不可靠。

## 十、结论

最小二乘的逻辑链条很短：定义平方残差和 → 利用其处处可微且凸的性质求偏导 → 得到正规方程 $X^{\top}X\theta=X^{\top}y$ → 解出 $a=S_{xy}/S_{xx}$、$b=\bar{y}-a\bar{x}$。在 $(0,1),(1,2),(2,2)$ 上它给出 $a=\frac12$、$b=\frac76$、残差 $(-\frac16,\frac13,-\frac16)$、$S=\frac16$。解的存在唯一性依赖 $S_{xx}>0$；当横坐标全相同时斜率不可识别。最后，估计出的直线描述的是**关联**，其因果解释、外推可靠性与对离群点的稳健性，都属于最小二乘之外、需要单独论证的问题。
