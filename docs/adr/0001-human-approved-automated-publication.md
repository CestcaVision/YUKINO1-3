# Require human approval for automated publication

Issue forms may initiate structured result updates or AI-assisted note drafting, but automation only creates a pull request. Publication requires the applicant to review and merge that pull request, because direct publication would reduce friction at the cost of authorship clarity, factual reliability, and control over admissions-facing claims.


Issue-driven generated learning notes now use the automatic publication flow in
[ADR 0005](0005-issue-driven-generated-note-publication.md), which supersedes this
decision for that workflow. Other automated publication remains subject to review.
